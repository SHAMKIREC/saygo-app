# SAYGO by NRV

SAYGO — мобильный курс разговорного английского для взрослых русскоязычных новичков.

## Что это сейчас

- первый бесплатный модуль из 12 уроков;
- буквы → звуки → первые фразы → первая проверка;
- в уроке: цель, понятное правило по-русски, аудио-образец, практика, тест, итог и следующий шаг;
- прогресс хранится на телефоне;
- распознавание речи показывает текст, который услышал браузер; это не оценка акцента.

## Учебная программа

Полный порядок, правила создания уроков и критерии качества: [CURRICULUM.md](CURRICULUM.md).

## Технически

Сайт работает на статическом HTML, CSS и JavaScript и публикуется через GitHub Pages. Никаких ключей, платёжных данных или фальшивых проверок подписки в клиенте нет.

## Чего приложение пока не обещает

- свободный английский за 12 уроков;
- профессиональную оценку акцента;
- настоящий доступ NRV Club;
- оплату 999 ₽.

Это будут отдельные этапы после проверки базового обучения на телефоне.
