# SAYGO by NRV

Мобильное приложение для разговорного английского с нуля.

## Первая версия

- Первые 12 уроков доступны бесплатно.
- Тренировка: слушать фразу, записать себя, прослушать результат.
- Записи остаются на устройстве пользователя.
- Далее: проверка подписки на Telegram NRV и платёж 999 ₽ за полный доступ.
