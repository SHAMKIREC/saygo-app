# ARCHITECTURE — SAYGO by NRV

## Текущий стек
Статическое PWA: HTML, CSS и JavaScript. Публикация: GitHub + Vercel.

## Текущие данные
Голос записывается MediaRecorder API и остаётся в памяти браузера до закрытия страницы. Озвучивание фразы — Web Speech API.

## План развития
1. Учебные данные и прогресс в локальном хранилище.
2. Supabase только когда появятся аккаунты, общий прогресс и доступ по подписке.
3. NRV Club: отдельный серверный модуль выдачи доступа. Telegram проверяется через бота при наличии прав бота в канале. Для Instagram, YouTube и Threads выбирается подтверждение, которое соответствует официальным возможностям площадок: OAuth-проверка либо одноразовый код из поста, видео или Threads-публикации.
4. Лаборатория идей: отдельные сущности «идея», «голос», «статус». Один пользователь голосует за идею один раз; публичный счётчик не раскрывает персональные данные. Модерация и публикация статуса — только через защищённый кабинет NRV.
5. Оплата и вебхуки — только серверно, с идемпотентностью и выдачей доступа после подтверждённой оплаты.
6. Распознавание речи подключается отдельным сервисом с понятными лимитами и политикой данных.

## Секреты
Ключей и токенов в клиентском коде нет. Все будущие ключи — только в переменных окружения хостинга.
